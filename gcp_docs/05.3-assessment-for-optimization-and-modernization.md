# Assessment for optimization and modernization

The assessment process for workload optimization and modernization already migrated into Google Cloud is similar to the assessment of workloads to be migrated into Google Cloud. What will change, primarily, is the sources of data to conduct the assessments. In Google Cloud, there are several out-of-the-box tools and services that you can use to obtain telemetry, utilization insights, and modernization recommendations about your applications running in Google Cloud.

What and how to optimize and modernize your applications will be based on your unique drivers and circumstances. Optimization focuses on applying changes to the current architecture and technology to reduce cost, adapt performance requirements, and incorporate lessons learned. Modernization focuses on taking your application to the next level, such as adopting serverless models (**Cloud Run**), managed Kubernetes (**GKE Autopilot**), cloud-native databases (**AlloyDB for PostgreSQL** / **Cloud Spanner**), and microservice architectures.

Follow the guidelines of the [prioritized applications assessment](./03-prioritized-applications-assessment.md). To further aid your optimization and modernization efforts on Google Cloud, see the following resources:

- [Google Cloud Cost Optimization Framework & FinOps Hub](https://cloud.google.com/architecture/framework/cost-optimization) provides architectural best practices, FinOps dashboards, CUD optimization, and cost-saving recommendations.
- [Google Cloud Active Assist & Recommender](https://cloud.google.com/recommender) recommends Google Cloud resource optimizations (such as Compute Engine Machine Type right-sizing, Idle VM & Persistent Disk detection, Cloud SQL right-sizing, and Committed Use Discount recommendations) using machine learning to analyze historical utilization metrics.
- [Compute Engine cost and capacity optimization](https://cloud.google.com/compute/docs/instances/apply-machine-type-recommendations-for-instances) helps manage compute resources using Custom Machine Types, Sustained Use Discounts (SUDs), Committed Use Discounts (CUDs), and Spot VMs.
- [Cloud Storage Insights & Autoclass](https://cloud.google.com/storage/docs/insights/datasets) delivers organization-wide visibility into object storage usage and activity trends, and automatically transitions objects across storage classes (Standard, Nearline, Coldline, Archive) to optimize costs.
- [Database Migration Service (DMS) & AlloyDB Modernization](https://cloud.google.com/database-migration) facilitates heterogeneous database modernization from legacy commercial engines (such as Oracle and Microsoft SQL Server) to cloud-native **AlloyDB for PostgreSQL** and **Cloud SQL** using Gemini-powered Conversion Workspaces.
- [Cloud Profiler](https://cloud.google.com/profiler) and [Gemini Code Assist](https://cloud.google.com/products/gemini/code-assist) provide continuous CPU/heap profiling and AI-assisted code modernization to improve application performance and reduce compute footprint.
- [Google Distributed Cloud (GDC)](https://cloud.google.com/distributed-cloud) delivers a consistent Google Cloud and GKE experience wherever you need it—from Google Cloud regions to on-premises data centers and the edge.
