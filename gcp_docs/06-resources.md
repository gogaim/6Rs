## Google Cloud migration, modernization & assessment services

- [Google Cloud Migration Center](https://cloud.google.com/migration-center) — Unified discovery, TCO assessment, right-sizing, and modernization fit (`mFit`) platform
- [Migrate to Virtual Machines (M2VM)](https://cloud.google.com/migrate/virtual-machines) — Agentless VM replication and rehosting to Compute Engine
- [Google Cloud VMware Engine (GCVE)](https://cloud.google.com/vmware-engine) — Managed VMware SDDC environment for rapid VMware workload relocation
- [Migrate to Containers (M2C)](https://cloud.google.com/migrate/containers) — Automated containerization of VM workloads to GKE and Cloud Run
- [Database Migration Service (DMS)](https://cloud.google.com/database-migration) — Serverless homogeneous and heterogeneous database migration with Gemini-powered Conversion Workspaces
- [Database Migration Assessment (DMA)](https://github.com/GoogleCloudPlatform/database-assessment) — Open-source assessment and sizing tool for migrating Oracle, SQL Server, MySQL, and PostgreSQL to Cloud SQL and AlloyDB
- [Google Compute Engine (GCE)](https://cloud.google.com/compute) — Customizable virtual machines with Sustained Use Discounts (SUDs) and Committed Use Discounts (CUDs)
- [Google Kubernetes Engine (GKE Standard & Autopilot)](https://cloud.google.com/kubernetes-engine) — Managed Kubernetes platform
- [Cloud Run](https://cloud.google.com/run) — Fully managed serverless container and function platform
- [Cloud SQL](https://cloud.google.com/sql) & [AlloyDB for PostgreSQL](https://cloud.google.com/alloydb) — Managed relational database services
- [Storage Transfer Service](https://cloud.google.com/storage-transfer-service) & [Transfer Appliance](https://cloud.google.com/transfer-appliance) — Online and offline large-scale data transfer
- [Cloud Interconnect](https://cloud.google.com/network-connectivity/docs/interconnect) & [Cloud VPN](https://cloud.google.com/network-connectivity/docs/vpn) — Hybrid network connectivity
- [Cloud Foundation Toolkit (CFT)](https://cloud.google.com/foundation-toolkit) — Terraform blueprints for Google Cloud landing zones
- [Google Cloud Active Assist & Recommender](https://cloud.google.com/recommender) — ML-powered right-sizing, idle resource detection, and CUD optimization
- [Cloud Storage Insights & Autoclass](https://cloud.google.com/storage/docs/insights/datasets) — Object storage analytics and automated tiering
- [Google Cloud Marketplace](https://cloud.google.com/marketplace) — SaaS and ISV software procurement
- [Google Cloud Pricing Calculator](https://cloud.google.com/products/calculator) — Target architecture run-cost estimation
